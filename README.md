# 🏦 Bank Account Simulation

A simple Java console application that simulates basic bank account operations such as account creation, deposits, withdrawals, and balance management.

## 📌 About the Project

Bank Account Simulation is a beginner-friendly Java project built to understand how Object-Oriented Programming can be applied to a real-world concept.

The application allows a user to create an account, make an initial deposit, withdraw money, and view the account balance through a console-based interface.

The project is being developed step-by-step, with additional validation and improvements added as the implementation progresses.

## ✨ Features

- 👤 Account creation
- 🔢 Automatic account number generation
- 💰 Initial deposit
- ➕ Deposit money
- ➖ Withdraw money
- 💳 Balance checking
- 🚫 Prevents withdrawal beyond the available balance
- 🔄 Multiple account operations

## ▶️ How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA or any Java IDE.
3. Compile the Java files.
4. Run `Main.java`.
5. Follow the instructions displayed in the console.
